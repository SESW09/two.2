      🛡 1. 프로그램 소개

      PhishGuard AI는 인공지능을 활용하여 문자 메시지와 이메일의 피싱·스미싱 위험 신호를 분석하는 보안 교육용 프로그램입니다.

      GPT 인공지능과 규칙 기반 분석을 결합하여 의심스러운 메시지의 특징을 파악하고, 사용자에게 위험 수준과 판단 근거, 안전한 대응 방법을 알려줍니다.

      주요 사용자: 학생, 교사, 일반 사용자

      개발 목적: 피싱 및 스미싱 예방과 개인정보 보호 의식 향상

      💡 이 프로그램은 실제 사기 여부를 확정하는 서비스가 아니라 위험 신호를 이해하도록 돕는 앱입니다.

      📱 2. 접속 및 설치 방법

      PhishGuard AI는 별도의 프로그램 설치 없이 웹브라우저에서 사용할 수 있습니다.

      1
      웹사이트 접속

      GitHub Pages에 배포된 PhishGuard AI 웹사이트에 접속합니다.

      2
      앱 실행

      홈페이지가 나타나면 'AI 메시지 분석 시작' 버튼을 눌러 프로그램을 이용할 수 있습니다.

      3
      스마트폰 설치

      브라우저의 앱 설치 기능을 사용하면 홈 화면에서 PhishGuard AI를 실행할 수 있습니다.

      Android 설치 방법

      1. Chrome 브라우저에서 앱에 접속합니다.
      2. 브라우저의 메뉴를 엽니다.
      3. '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.
      4. 설치 후 홈 화면에서 앱을 실행합니다.

      iPhone 및 iPad 설치 방법

      1. Safari 브라우저에서 앱에 접속합니다.
      2. 공유 메뉴를 선택합니다.
      3. '홈 화면에 추가'를 선택합니다.
      4. 추가를 완료하고 홈 화면에서 앱을 실행합니다.
      💡 기기나 브라우저 버전에 따라 설치 메뉴의 이름과 위치가 다를 수 있습니다. AI 분석에는 인터넷 연결이 필요합니다.

      🖥 3. 화면 구성 설명

      ⌂
      홈 화면

      프로그램 소개와 주요 기능, 피싱 예방 수칙을 확인합니다. 'AI 메시지 분석 시작' 버튼으로 분석 화면에 이동할 수 있습니다.

      ⌕
      AI 분석 화면

      메시지 입력창에 문자 내용을 붙여넣고 'AI 위험 분석하기' 버튼을 누릅니다. 예시 버튼으로 테스트할 수도 있습니다.

      ▤
      분석 기록 화면

      이전 분석의 날짜, 위험 등급, 규칙 기반 점수를 확인합니다. '전체 삭제' 버튼으로 기록을 지울 수 있습니다.

      ▥
      통계 화면

      총 분석 횟수, 위험 등급별 분포, 자주 발견된 위험 신호를 그래프로 확인할 수 있습니다.

      ⚙
      설정 화면

      서버 연결 상태를 확인하고, 앱 설치, 기록 삭제, 사용자 매뉴얼 기능을 이용합니다.

      🔎 4. 기본 사용 방법

      다음 3단계만 따라 하면 메시지 위험 분석을 진행할 수 있습니다.

      1
      메시지 입력

      하단 'AI 분석' 메뉴를 선택합니다. 메시지 입력창에 의심스러운 문자 또는 이메일을 붙여넣습니다. 개인정보는 먼저 삭제합니다.

      2
      AI 분석 실행

      'AI 위험 분석하기' 버튼을 누릅니다. 서버가 연결되어 있으면 규칙 기반 탐지와 GPT 분석을 시작합니다.

      3
      결과 확인

      위험 점수, 위험 등급, 의심 요소, 권장 대응 방법을 확인합니다. 결과는 참고용으로 활용합니다.

      📊 5. 위험 점수와 등급 이해하기

      규칙 기반 분석에서는 발견된 의심 표현을 바탕으로 0~100점의 참고 점수를 계산합니다.

      🟢 0~29점: 낮은 위험 신호

      🟡 30~59점: 주의가 필요한 위험 신호

      🔴 60~100점: 높은 위험 신호

      ⚠️ 위험 점수와 AI 위험 등급은 서로 다른 분석 방식으로 계산되므로 결과가 다를 수 있습니다. 점수가 낮더라도 안전하다는 뜻은 아닙니다.

      ⚠️ 6. 사용 시 주의사항

      • 실제 비밀번호, 인증번호, 계좌번호, 주민등록번호 등은 입력하지 마세요.
      • 메시지 안의 의심스러운 링크를 직접 클릭하지 마세요.
      • AI 분석 결과가 반드시 정확한 것은 아니므로 참고 자료로 활용하세요.
      • 메시지의 안전 여부는 공식 앱이나 공식 연락처를 통해 추가 확인하세요.
      • 인터넷 연결이 없으면 GPT 기반 분석 기능을 사용할 수 없습니다.
      • 분석 요약 기록은 사용하는 기기에 저장되며 설정에서 삭제할 수 있습니다.

      ❓ 7. 자주 묻는 질문

      Q1. AI 분석이 실행되지 않아요.

      인터넷 연결과 GAS 서버 연결 상태를 확인하세요. 설정 메뉴에서 '서버 연결 다시 시도'를 선택할 수 있습니다. API 사용량 제한에 도달했을 수도 있습니다.

      Q2. 위험 점수가 낮으면 안전한가요?

      아닙니다. 점수가 낮아도 피싱 메시지일 가능성이 있습니다. 점수는 탐지된 의심 표현을 나타내는 참고 지표입니다.

      Q3. 분석 기록은 어디에 저장되나요?

      최근 분석 요약은 현재 브라우저의 로컬 저장소에 저장됩니다. 메시지 원문은 기록에 저장하지 않습니다. 서버에서는 비식별 통계가 별도로 저장될 수 있습니다.

      Q4. 인터넷 없이 사용할 수 있나요?

      이전에 저장된 앱 화면과 기본 안내는 오프라인에서도 볼 수 있지만, AI 분석에는 인터넷 연결이 필요합니다.

      Q5. 앱 설치 버튼이 보이지 않아요.

      브라우저가 설치 기능을 지원하는지 확인하세요. PWA 아이콘과 매니페스트 설정이 정상적으로 배포되어 있어야 합니다.

      Q6. 개인정보가 외부로 전송되나요?

      입력 메시지는 분석을 위해 GAS와 OpenAI API로 전송됩니다. 서버가 일부 개인정보를 자동으로 가리지만 완벽하지 않을 수 있으므로 입력 전에 직접 삭제해야 합니다.
